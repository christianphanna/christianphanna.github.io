## Work Flow

### Video 1
1. Set Time Frame for Simulation: 5000 MYA (Using 600-0 MYA)
2. Save Project Files in One Folder.
3. Create 12 Cratons
	- Give them each a plate ID. 
	- **ABOUT 1000-4000km diameter in size.**
4. Create a Supercontinent of Continental Crust around the Cratons.
	- **ABOUT 25-30% of the total planet mass.** (Continent Mass / 4x 3.14 x Planet Radius^2)
5. Create Rifts cutting across the Continental Crust
6. Create **Failed** Rifts partially across the Continental Crust from T-Junctions.

---
### Video 2
7. Duplicate Supercontinent to Create Continents for Rifting
8. Set Up Rotation Text File
9. Rotate Continents
	Rotation Speeds:
		10-20: Subducting Oceans
		5-10: Recent Subduction Collisions
		2-5: Active Margin Continent
		0-2: Passive Margin Continent
10. Fix Continental Drift in Rotation Text File
11. Create Flowlines Between Drifting Continents

---

    - Appear on Leading Edge
